1. Getting Started

To begin your geophysical survey, launch the AnyScan209 application and ensure all necessary system permissions—specifically Storage (for project saving) and Bluetooth/Location (for hardware communication)—are granted. Upon the first launch, the Dashboard will initialize. From here, you can select 'New Project' to define your scanning parameters or 'Open Project' to load previously saved database files (.db or .json) for further analysis and visualization.

2. Setting Up Operating Modes

AnyScan209 is engineered for versatility, supporting two primary operational modes:

  • Internal Magnetic Sensor Mode: This mode utilizes the smartphone's built-in magnetometer. It is ideal for baseline testing and surface-level magnetic field monitoring. Important: To minimize interference from the user's body, it is recommended to mount the device on a non-magnetic (fiberglass or wooden) rod during operation.
  • External Sensor Mode (Hardware-Ready): This mode is designed for advanced exploration. It enables the app to receive real-time data packets from external microcontrollers (e.g., Arduino, ESP32, or AVR-based systems) via a Bluetooth serial connection. Ensure your external sensor module outputs raw data values within the 0-1024 range for optimal software scaling and rendering.

3. Project Workflow

To ensure data integrity, follow this standard scanning procedure:

  1. Grid Definition: Set the exact dimensions for your scan area. Input the total number of survey lines and the number of steps per line to create an accurate map grid.
  2. Metadata & Storage: Assign a unique, descriptive name to your project. This ensures that all telemetry data is logged into a dedicated local file directory.
  3. Initialization: Tap the "Initialize" button to prepare the database.
  4. Scanning & Rendering: Once initialized, proceed to the 3D Rendering interface. As you move along the grid, the software will render real-time topographical graphs and color-coded heatmaps. Use the live preview to identify anomalies instantly.

4. Bluetooth & Hardware

If you experience data streaming latency or connection drops in External Mode, follow these troubleshooting steps:

  • Reset Connection: Long-press the Bluetooth connection icon on the interface to force a re-handshake with the external module.
  • Baud Rate Sync: Verify that the baud rate of your external hardware (e.g., 9600 or 115200) matches the communication protocol configured within the app settings.
  • Signal Integrity: Keep the Bluetooth module free of electromagnetic obstacles. Ensure no other high-energy electronic devices are interfering with the wireless bridge.
  • Background Processes: Ensure that no other background applications are attempting to reserve the device's Bluetooth stack, as this can lead to serialized data corruption.
